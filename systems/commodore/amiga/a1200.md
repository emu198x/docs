# Amiga A1200 regional configurations

The implemented PAL and NTSC configurations have separate fixed machine owners,
`machine-commodore-amiga-a1200-pal` and `machine-commodore-amiga-a1200-ntsc`.
Shared AGA wiring lives in `common-commodore-amiga-aga`. Both ship through
`emu198x-amiga` and the existing Amiga runtime. Stock RAM is 2 MiB chip RAM;
RAM and firmware choices remain profiles of the selected regional board.

The profile IDs remain `commodore-amiga-a1200-aga-pal` and
`commodore-amiga-a1200-aga-ntsc`. Native aliases `a1200` and `a1200-ntsc` remain.
The new registry owner IDs omit `aga`. Existing v66 save fields are unchanged;
a fixed owner rejects a foreign-region restore before mutation.

Commodore's A1200 schematics show distinct regional oscillator fittings and
PAL-only video components. These owners cover the two implemented regional
configurations, without qualifying every PCB revision or chip population.
See the [ownership decision](https://github.com/emu198x/emu198x/blob/main/knowledge/decisions/a1200-regional-board-owners.md).

Each owner has seven direct invariant tests. Eight immutable pre-split v66
specimens cover both regions, progressive and interlaced video, and boundary
and debugger half-CCK saves. They compare original save bytes, the first three
resumed frame packets, every emitted audio sample, elapsed clocks and the
complete final save. Held controls release during continuation. The shared
resampler loads fixed coefficient bits to retain exact history across hosts.

Separate native captures show each region at the Kickstart 3.1 insert-disk
screen after 250 native fields. This checks firmware execution without an
inserted disk; it does not qualify Workbench, a software library, every PCB,
native menu interaction or host audio devices. ROM bytes are local inputs and
are not included in the fixtures or documentation.

The public player remains pinned to a constructor for A500+A501. A1200 board
pages omit an embed until a qualified module supports the exact profile.
The aggregate Amiga route remains for the still-grouped OCS/ECS configurations.

See [source PR #2226](https://github.com/emu198x/emu198x/pull/2226) and the
[plan and retained evidence](../../../plans/2026-11-01-a1200-regional-board-owners.md).
