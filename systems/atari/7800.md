# Atari 7800 ProSystem

## Status: Native cartridge games render; UI, script, and MCP are available

The current emulator is a native 7800-mode machine: 6502C “Sally”, MARIA,
RIOT, a thin TIA layer, 4 KB RAM, and cartridge banking. It boots from the
cartridge reset vector without waiting for a BIOS. A synthetic cartridge boot
runs in CI; the ROM-gated smoke test proves a real game gets past its DLI wait
and produces a non-uniform MARIA frame.

## What works

- **MARIA display lists** — DLL/zone walk, direct and indirect graphics, holey
  DMA, four- and five-byte DL entries, DLI-to-NMI, WSYNC, palettes, background,
  colour kill, and 160A/320A output. See [MARIA](../../chips/atari-maria.md).
- **Cartridges** — flat 16/32/48 KB ROMs and the current 8×16 KB SuperGame
  banking; `.a78` headers are stripped.
- **Input** — joystick through RIOT port A, console switches through RIOT port
  B, and two fire buttons through the TIA input registers.
- **Regions and runtime** — NTSC/PAL profiles, snapshots, native verifier
  window, scripted/headless operation, and MCP operation.

## Not implemented / accuracy gaps

- **MARIA mode coverage** — 160B, 320B/C/D, Kangaroo transparency, and distinct
  border-control behaviour are missing.
- **DMA granularity** — MARIA builds a scanline through a memory-read closure
  and returns one aggregate CPU-stall budget. Exact, pin-visible bus ownership
  remains to be modelled.
- **TIA audio** — controller inputs work, but the audio registers do not yet
  synthesise the two TIA channels.
- **6532 cadence** — Atari documents SALLY dropping from about 1.79 MHz to
  1.19 MHz during 6532 access. The machine currently ticks CPU and RIOT at the
  normal divide-by-two cadence throughout.
- **Hardware breadth** — the mapper set is narrow, and 2600 compatibility mode,
  authentication transition, light gun, and high-score cartridge are absent.

## Known unknowns / disproven hypotheses

- **DISPROVEN: “the black screen is a missing BIOS.”** Asteroids executes its
  own reset vector and waits on a zero-page counter advanced by its DLI NMI.
  The real fault was a three-bit misreading of MARIA `CTRL`: a game setting
  `DM=10` was interpreted as DMA off, so MARIA never walked the display list,
  never raised DLI, and the game waited forever. The corrected map puts DMA in
  bits 6–5, colour kill in bit 7, and Kangaroo in bit 2.
- **PAL vertical placement is not sourced.** The 288-line output window is
  region-correct, but the primary guide is NTSC and does not locate PAL MARIA's
  active field. A PAL timing source or hardware capture would settle it.

## Validated against

- Atari, *7800 Software Guide* — primary hardware inventory, MARIA display-list

  Provenance: `reference/by-system/atari-7800/atari-7800-software-guide.txt`.
- The project's source distillation at
  `reference/by-system/atari-7800/atari-7800-reference.md`.
- MAME `maria.cpp` and MiSTer 7800 `DMA.sv` — implementation precedent for
  entry parsing and CTRL behaviour.
- Synthetic cartridge CI and the ROM-gated `cart_boot` rendered-frame test.

## Timing & cycle-accuracy

- **Master clock and dividers** — the machine advances at the 3.579545 MHz NTSC
  or 3.546894 MHz PAL colour clock; a line is 228 colour clocks. CPU and RIOT
  normally tick every second colour clock.
- **Timing model realised** — scanline-batched MARIA DMA. Its returned budget
  withholds CPU ticks at the start of the line; WSYNC withholds them until the
  next line, and DLI drives NMI.
- **CPU timing** — `emu198x-mos-6502` is the pin-driven, cycle-accurate CPU core.
  Its CPU oracle does not validate MARIA's system-bus timing.
- **Distance to full cycle-accuracy** — pin-visible MARIA DMA, exact fetch
  accounting, access-dependent RIOT cadence, the complete graphics-mode matrix,
  and TIA audio.

## Tooling & drivability

- **Script / MCP** — `--script` and `--mcp` are present, with shared runtime
  queries, memory access, stepping, screenshots, and controller input.
- **Native window** — yes, through the shared `emu198x-ui` verifier shell.
- **Disassembler** — supplied through the shared 6502 ISA/disassembly layer.

## Peripherals & connectivity

- **Emulated now** — cartridge, two-button joystick, and console switches.
- **Period peripherals** — Pro-Line controllers, light gun, high-score
  cartridge, and the console's 2600 compatibility surface.
- **Internet-capable** — **No**: no period network/modem path or established
  modern network peripheral is currently in scope.

## Crates

| Crate | Role |
|---|---|
| `emu198x-mos-6502` | SALLY-compatible CPU core |
| `atari-maria` | Display-list processor |
| `mos-riot-6532` | Joystick, switches, and timer |
| `machine-atari-7800` | Board wiring and cartridge model |
| `runtime-atari-7800` | Profiles, snapshots, input, and queries |
| `emu198x-atari-7800` | UI, script, and MCP binary |

## ROMs

No BIOS is required by the current native-mode model. Supply an `.a78` or
`.bin` cartridge image.

## Launch

```sh
cargo run --release -p emu198x-atari-7800 -- --cart asteroids.a78
cargo run --release -p emu198x-atari-7800 -- --script --cart asteroids.a78 --frames 300 --screenshot a.png
```
